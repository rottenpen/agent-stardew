# 第一批视觉素材

应用标识融合像素鸡与蓝鲸，配套提供农场和农务助手插画。四张图片均由内置 `image_gen` 生成，作为桌面界面原型母图。

| 文件 | 用途 | 尺寸 | 透明背景 |
|---|---|---|---|
| [app-icon-chicken-whale-v1.png](app-icon-chicken-whale-v1.png) | 应用图标概念 | 1254 × 1254 | 是 |
| [welcome-farm-day-v1.png](welcome-farm-day-v1.png) | 欢迎与首次设置 | 1536 × 1024 | 否 |
| [agent-farmer-idle-v1.png](agent-farmer-idle-v1.png) | 等待目标的辅助插画 | 1254 × 1254 | 是 |
| [agent-farmer-working-v1.png](agent-farmer-working-v1.png) | 补能力过程的辅助插画 | 1254 × 1254 | 是 |

应用图标的多尺寸版本和 `.icns`／`.ico` 尚待制作。图片文件保持生成后的原始尺寸与 alpha。

完整用途与后续清单见[视觉素材规划](../../docs/visual-assets.md)，文件元数据见 [manifest.json](manifest.json)，最终提示词与参考关系见 [prompts.json](prompts.json)。

## 运行面板预览

[panel-preview.png](panel-preview.png) 为 2026-09-19 从本项目运行面板截取的浏览器画面，展示季节日历、体力条、背包和农场日记。画面使用明确标记的模拟数据，不是游戏截图，也不代表真实游戏任务已完成；此文件供根目录 README 展示，不属于生成插画母图。
