# 视觉素材规划

产品主标识融合星露谷像素鸡与 DeepSeek 蓝鲸：红冠、黄喙、白色鸡头，结合蓝鲸身体和上扬尾鳍。界面配套使用田园像素风插画，表现游玩和完善能力的过程。

首批文件位于 `assets/visual/`。用途、实际尺寸与透明度见 [素材清单](../assets/visual/README.md)，最终生成提示词保存在 `prompts.json`。这些文件是原型母图，平台图标与小尺寸版本在接入时单独验收。

## 1. 按用途组织素材

| 类型 | 内容 | 获取与使用方式 |
|---|---|---|
| 产品标识 | 鸡与鲸融合的像素图标 | 应用头像与桌面图标的概念母图 |
| 场景插画 | 农场欢迎图、待机助手、修理工具 | 项目配套素材，随应用交付 |
| 实际游戏素材 | 当前物品、作物、工具、NPC 图像 | 接入时从实际游戏及已加载 Mod 的资源取得，绑定资源标识与版本 |
| 操作控件 | 开始、暂停、停止、设置、展开 | 复用 dsh 的组件与图标规范，文字和状态由代码渲染 |

欢迎插画不作为当前农场截图，插画中的物品不充当背包物品的精确图像。游戏资源缺失时显示名称与通用占位符。任务状态与完成判据始终来自真实观察和验证结果。

## 2. 风格与配色

标识采用简洁像素轮廓和少量色阶，以蓝色、白色、红冠和黄色喙形成辨识。场景插画使用松林绿、木棕、水蓝和草帽金色；木质农务助手用于欢迎与修理场景。

| 目标颜色 | 色值 | 用途 |
|---|---|---|
| 蓝鲸蓝 | `#4D6BFE` | 主标识和品牌强调 |
| 松林绿 | `#244B3C` | 田园环境和深色背景 |
| 叶绿 | `#78A85A` | 植物与成长元素 |
| 蜜金 | `#D5A64B` | 草帽、木质亮部 |
| 木棕 | `#AD7042` | 土壤、房屋、工具台 |
| 水蓝 | `#68AFBF` | 水源和农具 |

色值是生成与搭配方向，图片允许自然变化。界面文字的对比度在实际 UI 中检查。图片不内嵌按钮、进度条或文案，便于主题适配与翻译。

## 3. 分批制作

| 阶段 | 素材 | 用途与数量 |
|---|---|---|
| P0 | 鸡鲸应用图标概念 | 1 张透明 PNG 母图 |
| P0 | 春日农场欢迎图 | 1 张横版背景，用于首次设置和欢迎区域 |
| P0 | 待机农务助手 | 1 张透明插画，用于等待目标 |
| P0 | 修理工具的农务助手 | 1 张透明插画，辅助表现补能力过程 |
| P1 | 主标识的小尺寸与平台版本 | 验证 16、32、64、128 像素辨识度，制作 `.icns`／`.ico` |
| P1 | 鸡鲸状态变体 | 观察、游玩、暂停、完成、需要帮助，5 张透明图 |
| P1 | 夜间农场与异常空状态 | 1 张夜景，未连接／无任务／恢复中各 1 张小插画 |
| P2 | 四季与天气背景 | 按实际页面需要追加 |
| P2 | 短动画 | 明确帧尺寸与节奏，提供静态替代和减少动态效果选项 |

本轮交付 P0 四张母图。P1 和 P2 为后续规划。

## 4. 文件与接入约定

按用途、状态和版本命名。`manifest.json` 提供 ID、文件路径、用途、尺寸、透明度及内容哈希，`prompts.json` 保存生成工具、参考关系和最终提示词。新增版本保留独立文件名。

透明插画保留原始 alpha，场景图保留完整构图。应用图标在打包时处理平台背景和外形。生成的像素风母图与严格像素网格的 sprite 分开管理；小尺寸和逐帧动画需专门制作。

实际游戏资源读取属于后续接入能力，需要定义资源标识、缓存失效和版本匹配；取得的资源进入运行缓存。仓库维护接入协议和来源记录。

## 5. 接入前检查

- 图标能辨认出鸡头与鲸尾，场景助手的形象保持一致。
- PNG 可解码，尺寸和 alpha 已登记；透明图在浅色与深色底上检查边缘。
- 插画不包含固定文案、伪造游戏 HUD 或水印。
- 小尺寸、平台图标与完整母图分别验证，不把概念 PNG 直接当作安装图标完成品。
