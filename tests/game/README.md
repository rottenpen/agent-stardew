# 实机验收

`pnpm test:game` 仅读取并保存当前游戏快照，不执行游戏动作。它拒绝将 `mock` 结果记为实机结果；运行目录为 `work/runs/game-observation-<时间戳>/`。

完整农务验收使用专用测试存档。存档准备后，在游戏完全退出时复制备份到 `work/game-fixtures/<测试编号>/baseline/`，记录来源、游戏版本与存档文件 SHA-256。恢复只操作该专用测试存档目录，不能删除或覆盖其他用户存档。存档及包含个人数据的运行记录不提交仓库。

基线要求：春季、单人农场，角色有锄头、浇水壶、5 颗防风草种子及足够体力；确认可耕地和回屋路线。通过正常游戏准备基线，验收期间由工具遵守资源及碰撞约束。

每次运行记录：

1. Mod、CLI、插件版本与构建哈希，dsh 版本及模型配置名称。
2. 初始快照、具体地块、背包和原始日期。
3. 每个动作的请求 ID、动作 ID、终态、错误及前后快照。
4. 睡前 5 个地块均有作物且 `watered=true`；睡后日期推进。睡后土壤可能变干，因此保留睡前证据。
5. 模型调用量、真实耗时、游戏内耗时、人工干预和必要截图。

恢复同一专用基线后重复 5 次，至少 4 次成功；全部失败也要记录。人工执行命令、固定脚本和 dsh 自主推理分别注明，不能混合统计为 Agent 成功率。
